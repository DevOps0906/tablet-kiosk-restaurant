# 손님 화면 명세 — 식당

> 화면마다 스탠드형(세로) · 갤럭시탭형(가로) 디자인이 있고, **동작은 같습니다.** 레이아웃만 다릅니다.
> 공통 동작은 core `docs/04`(결제) · `docs/05`(출력) · `docs/06`(쿠폰)을 따릅니다.

## 1. 시작 — 매장 / 포장 선택

- 디자인: [`00-start`](../screenshots/00-start.png) (스탠드) · [`sw-00-start`](../screenshots/sw-00-start.png) (갤럭시탭)

**구성**

- 가게 이름 · 로고 · 대표 사진(세팅 2단계에서 올린 것)
- "어디서 드시나요?" + `매장` / `포장` 큰 버튼
- "선택하신 내용은 주문서에 함께 인쇄돼요"
- (갤럭시탭형) 영업시간 표시

**예외 · 규칙**

- `한국어 · English`, `큰 글씨` 버튼은 MVP에서 숨김

**다음**: 매장 / 포장 선택 → 주문 세션 시작 → 메뉴

## 2. 메뉴 선택

- 디자인: [`Main`](../screenshots/Main.png) (스탠드) · [`sw-01-menu`](../screenshots/sw-01-menu.png) (갤럭시탭)

**구성**

- 상단 매장 / 포장 탭 — 시작 화면 선택과 같은 쪽 선택 상태, 눌러서 바꿀 수 있음 (주문서 인쇄 값도 바뀜)
- 분류 칩: 고기 · 식사 · 찌개 · 탕 · 주류 · 음료
- 메뉴 카드: 사진 자리 · 이름 · 가격 · 배지 · 담은 수량
- 품절 메뉴는 흐리게 + `품절`, 누를 수 없음
- 하단 장바구니 요약: 개수 · 합계 · `주문 확인 ›`

**예외 · 규칙**

- 장바구니 비어 있으면 `주문 확인` 비활성

**다음**: 메뉴 누름 → (업종 itemConfigurator) → 장바구니

## 3. 메뉴 — 주류 · 음료

- 디자인: [`01b-drinks`](../screenshots/01b-drinks.png) (스탠드) · [`sw-01b-drinks`](../screenshots/sw-01b-drinks.png) (갤럭시탭)

**구성**

- 19세 안내 배너
- 주류 9종 중 주류 5종에 19 배지
- 담기 동작은 메뉴 화면과 동일

**예외 · 규칙**

- 주류만 담고 결제해도 됨 (제한 없음)

## 4. 주문 확인 (장바구니)

- 디자인: [`02-cart`](../screenshots/02-cart.png) (스탠드) · [`sw-02-cart`](../screenshots/sw-02-cart.png) (갤럭시탭)

**구성**

- 매장 / 포장 배지, 총 개수, `전체 삭제`
- 항목: 이름 · 옵션 요약 · 수량 − + · 삭제 · 금액
- 상품 금액 · 결제 금액
- `더 담기` / `결제하기 ›`

**예외 · 규칙**

- 수량 0 → 삭제 확인
- 업종 cartRules 위반 시 안내 후 결제 불가

**다음**: 결제하기 → 결제 방법

## 5. 결제 방법 선택

- 디자인: [`03-pay-method`](../screenshots/03-pay-method.png) (스탠드) · [`sw-03-pay`](../screenshots/sw-03-pay.png) (갤럭시탭)

**구성**

- 주문 요약 + 매장 / 포장 배지 + 결제 금액
- `전체결제` / `더치페이` **좌우 버튼** (같은 크기)
- 점선 `쿠폰 사용 — 시리얼 번호 입력 · 바코드 스캔` 진입 바 (`specs/coupon.md`)
- 안내 박스
- `주문 내역으로` / `직원 호출`

**예외 · 규칙**

- 카드 단말 미연결 → 결제 버튼 막고 직원 호출 안내
- 인터넷 끊김 → 결제 불가 안내

**다음**: 전체결제 → 카드 승인 / 더치페이 → 분할 방식

## 6. 더치페이

- 디자인: [`04-dutch`](../screenshots/04-dutch.png) (스탠드) · [`sw-04-dutch`](../screenshots/sw-04-dutch.png) (갤럭시탭)

**구성**

- 방식 탭: N등분 · 메뉴별 · 금액 입력
- 전체 · 결제 완료 · 남은 금액
- 결제자 행: 완료 / 진행 중 / 대기
- 방식별 입력 (인원 수, 메뉴 선택, 금액)
- `N번째 0,000원 결제하기`
- `직원 호출`

**예외 · 규칙**

- 결제 건 거절 → 그 건만 재시도
- 손님 중간 취소 불가 (직원 PIN)
- 진행 중 무입력 초기화 없음

**다음**: 남은 금액 0원 → 주문 확정 → 출력 → 완료

## 7. 주문 완료

- 디자인: [`05-done`](../screenshots/05-done.png) (스탠드) · [`sw-05-done`](../screenshots/sw-05-done.png) (갤럭시탭)

**구성**

- "주문이 접수되었어요", 매장 / 포장 · 호출번호 크게 (`A-017`)
- 업종 안내 문구 (`docs/01`)
- 30초 뒤 처음 화면 안내
- `영수증 출력` / `처음으로`

**예외 · 규칙**

- 출력 실패여도 완료 화면은 정상 표시 (대기열 처리)

**다음**: 처음으로 → 시작 화면, 세션 초기화

## 수용 시나리오

아래가 모두 되면 식당 손님 흐름 완료입니다. (core 공통 시나리오 `docs/10` 2장 + 아래)

- [ ] 돼지갈비 1인분만 담기 → 최소 2인분 안내, 결제 불가
- [ ] 된장찌개만 담기 → 고기 주문 필요 안내
- [ ] 소주 담기 → 19 배지, 주문서에 신분증 확인 줄
- [ ] 더치페이 메뉴별: 돼지갈비 3인분을 결제자 3명에게 1인분씩 배정
- [ ] 주방 프린터 분류 설정 시 고기 · 식사 주문서가 따로 출력
- [ ] 쿠폰 `첫 방문 감사 5,000원 할인` 72,000원 → 67,000원
